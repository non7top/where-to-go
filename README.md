# Where to go

A map-first trip destination picker for East and Southeast Asia. Pick a time of year on the dial and the map colors every area by how warm it feels, marks rain seasons, and shows festivals and seasonal sights. Everything runs in the browser from static JSON files; there is no server.

Live: https://non7top.github.io/where-to-go/

## What it does

- Color by felt daytime high (wind adjusted), from blue (cold) through green (about 17-23 C) to red (hot), with rain and monsoon hatching.
- A year dial (drum or ring view) with seasons marked. The selected 15-day section drives the map, and the label counts days or months until it.
- Areas from country to city level, zoom-cuts such as Okinawa, and a Cities menu of airport cities as starting points.
- Events with a peak date and a spread: festivals, fairs, concerts, and seasonal fronts that sweep across a country (cherry blossom, autumn leaves, ginkgo, plum, hydrangea, higanbana and others). Local names come first, with aliases for search.
- Icons on the map, grouped into sectored badges where they overlap, plus highlight stars for named spots when zoomed in.
- A right-hand panel with the top green places and the events for the selected period. Draw a rectangle (Shift-drag) to narrow both lists.
- Global search over places and events.

## Run it

Everything runs in containers; the host needs only Docker and make.

```text
make install      # npm dependencies into a named volume
make dev          # dev server on http://localhost:5173/where-to-go/
make build        # production build into dist/
make preview      # serve dist/ on http://localhost:4173/where-to-go/
make standalone   # single-folder build that also opens from file://
make lint
make test
make data         # regenerate areas and climate (output is committed)
npm run links     # check every event link (run through make shell)
```

## Data

Files in `public/data`:

- `areas.geojson`, `land.geojson`, `climate.json`: generated by `make data` from Natural Earth and NASA POWER (2015-2024 monthly means). Inputs for the generator are in `data-src`.
- `event-files.json`: the list of event files to load.
- `events.json`, `concerts.json`, `fronts.json`, `japan-festivals.json`, `japan-viewing.json`: hand-edited events. The format is described by `specs/001-static-map-prototype/contracts/events.schema.json`, and `make test` validates every file against it.
- `shortcuts.json`: the zoom shortcuts.

Event dates are typical peaks, not forecasts, and are marked approximate where they vary. To add events, put them in one of the event files (or a new file listed in `event-files.json`).

## Hosting

Pushing to `master` runs `.github/workflows/pages.yml`, which builds in the project container and publishes `dist/` to GitHub Pages. The Vite `base` is `/where-to-go/`.
